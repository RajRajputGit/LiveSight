# Glossary

- **AI inference:** Running a trained model on new input to obtain predictions.
- **Bounding box:** Rectangle describing an object's location in an image.
- **ByteTrack:** Multi-object tracking approach that associates detections across frames.
- **Confidence threshold:** Minimum detector score accepted by the application.
- **Detection:** A per-frame prediction containing class, score, and location.
- **Edge computing:** Processing data close to where it is captured, such as on a device near a camera.
- **Event:** Structured record created when a business rule is satisfied.
- **FPS:** Frames processed or displayed per second; always specify which measurement is meant.
- **Inference latency:** Time spent running model inference for an input.
- **MOT:** Multi-object tracking; maintaining trajectories for multiple objects.
- **ONNX:** A model exchange format used by supported inference runtimes.
- **ReID:** Re-identification; matching appearance features to help associate an object with an earlier track.
- **RTSP:** A network protocol commonly used to control/transport IP camera streams.
- **TensorRT:** NVIDIA inference optimization/runtime technology for supported NVIDIA hardware.
- **Track ID:** Temporary identifier assigned by a tracker to a trajectory; not a real-world identity.
- **WebSocket:** A persistent, bidirectional connection useful for live updates.
- **YOLO:** A family of object detection models.
- **Zone intrusion:** An event generated when an object's selected reference point crosses into a configured region.
